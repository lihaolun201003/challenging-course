# 甲醛蜂鸣器报警

## 已确认接线

| 蜂鸣器模块 | NUCLEO-F411RE |
| --- | --- |
| VCC | 5V |
| GND | 开发板 GND，所有模块共地 |
| I/O | PB10 / D6（CN9 第 7 脚） |

模块使用 5V 供电，I/O 使用开发板的 3.3V GPIO 逻辑，高电平持续响、低电平停。用户已用独立测试程序确认此接法能响。

## 报警规则

采用最近一帧完整且校验通过的 PMS5003ST 读数。只有该帧未超时、传感器错误码为 0，并且状态为 `Warmup` 或 `Live` 时才判断浓度。

| 条件 | 蜂鸣器 |
| --- | --- |
| HCHO > 0.030 mg/m³（> 30 μg/m³） | PB10 保持高电平，持续响 |
| HCHO ≤ 0.030 mg/m³（≤ 30 μg/m³） | PB10 低电平，停止 |
| 没有有效帧 / 最近有效帧距今达到 10 秒 / 传感器错误码非 0 | PB10 低电平，停止 |

`Warmup` 期间同样允许报警；等于阈值时不报警。长度或校验不合格的数据不会更新当前读数，超时以最近完整、校验通过的帧的接收时间判断。独立测试工程的 500 ms 响、1500 ms 停只是硬件验证时序；正式 AIR 按浓度持续控制，不沿用该测试循环。
